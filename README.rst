================
  AerodynamicsWM
================

.. image:: /aerodynamics.jpg
   :alt: AerodynamicsWM

An experimental infinite-canvas window manager for X11.

Features
========

* Infinite canvas
* Floating windows
* Physics
* X11 support
* Lua configuration
* Shader wallpapers

Build
=====

::

    stack build

Run
===

::

    stack exec aerodynamics-wm
